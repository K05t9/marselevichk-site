# Константин Марсельевич 2004 — тру 1337 кодер

Личный сайт-замок в эстетике нулевых: готика + кислотная цветастость, летучие
мыши, кресты, призрак, живой счётчик и гостевая книга с мини-API.
React + Vite на фронте, чистый Node (без зависимостей) на бэкенде.

- Прод: http://marselevichk.ru → http://31.77.149.158 (nginx + systemd, Ubuntu 24.04)
- Локально: `npm run dev` + `node server/server.cjs` (API на :3001)

## Команды

```
npm install      # один раз
npm run dev      # дев-сервер (проксирует /api на localhost:3001)
node server/server.cjs   # локальный API
npm run build    # прод-сборка в dist/
npm run deploy   # собрать + залить фронт на VPS по SSH
```

## Что внутри (фишки)

- Живой счётчик посетителей и гостевая книга через `/api` (все видят всех);
  если бэкенд спит — деградация в localStorage, сайт не ломается.
- «Кто онлайн» — heartbeat раз в минуту с погонялом.
- Генератор погонял 2004 (`xXx_Тёмный_Волк_666_xXx`).
- Тема Y2K (перламутр/хром) против готики — переключатель в сайдбаре.
- Ночной режим: с 23:00 до 6:00 тьма густеет, мыши летят чаще.
- Настоящий MIDI-плеер: Web Audio синтезирует готическую мелодию, крутилка
  громкости честная.
- Заголовок вкладки умоляет остаться, когда уходишь со страницы.
- Курсор — летучая мышь, машет крыльями.
- Кресты на фоне, рой мышей, призрак, туман, вращающиеся черепа-стражи.

```
ssh -i C:\Users\Konstantin\.ssh\marselevichk_server root@31.77.149.158
```

## Сервер (31.77.149.158)

- nginx: конфиг `/etc/nginx/sites-available/marselevichk` (копия в
  `deploy/marselevichk.conf`), корень сайта `/var/www/marselevichk`,
  `/api/` проксируется на `127.0.0.1:3001`.
- API: systemd-сервис `marselevichk-api` (юнит в `deploy/marselevichk-api.service`),
  код `server/server.cjs`, данные в `/opt/marselevichk-api/data/*.json`.
- Node на сервере: системный (v18, `apt install nodejs`).

## Деплой

Ручной: `npm run deploy`.
Автоматический: GitHub Actions (`.github/workflows/deploy.yml`) — при пуше в
`main` собирает и заливает фронт + API, рестартует сервис. Нужен секрет
`DEPLOY_SSH_KEY` (приватный ключ) в настройках репозитория.

## Домен и HTTPS

DNS: A-записи `@` и `www` → `31.77.149.158` (reg.ru). Когда домен резолвится
из интернета, выпустить сертификат:

```
certbot --nginx -d marselevichk.ru -d www.marselevichk.ru --redirect -m konstantin@marselevichk.ru --agree-tos -n
```

## Как связаны субдомены

Страницы — хэш-роуты (`#/chat`, `#/lab`). Для реальных субдоменов
(`chat.marselevichk.ru`) — либо отдельные сборки, либо nginx-рерайт субдомена
на путь + мини-роутер в `src/App.jsx` читает `window.location.hostname`.
