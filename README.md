# Константин Марсельевич 2004 — тру 1337 кодер

Личный сайт в эстетике ранних нулевых. React + Vite. Никаких CSS-фреймворков —
только ridge-бордеры, Comic Sans и выворотка.

- Прод: http://marselevichk.ru → http://31.77.149.158 (nginx, Ubuntu 24.04)
- Локально: `npm run dev`

## Команды

```
npm install      # один раз
npm run dev      # дев-сервер
npm run build    # прод-сборка в dist/
npm run deploy   # собрать + залить на сервер 31.77.149.158
```

## SSH-доступ к серверу

Ключ: `C:\Users\Konstantin\.ssh\marselevichk_server` (ed25519, публичный уже
установлен в `/root/.ssh/authorized_keys` на сервере).

```
ssh -i C:\Users\Konstantin\.ssh\marselevichk_server root@31.77.149.158
```

## Деплой и DNS

nginx на сервере: конфиг `/etc/nginx/sites-available/marselevichk` (копия в
`deploy/marselevichk.conf` в репо), корень сайта `/var/www/marselevichk`.

**Домен marselevichk.ru пока не резолвится.** В панели регистратора домена
добавь A-записи на сервер:

```
marselevichk.ru      A    31.77.149.158
www.marselevichk.ru  A    31.77.149.158
```

Когда DNS заработает — можно выпустить HTTPS-сертификат:

```
apt install certbot python3-certbot-nginx -y
certbot --nginx -d marselevichk.ru -d www.marselevichk.ru
```

## Страницы

- **Главная** (`#/`) — приветствие, спека компа, любимые фильмы, гостевая книга
  (записи живут в localStorage), веб-ринг, счётчик посещений.
- **МОИ САЙТЫ** (`#/sites`) — портфолио реальных сайтов. Первый экспонат —
  [институт-трезвости.рф](https://институт-трезвости.рф/); новый сайт = новый
  «экспонат» в `src/pages/Sites.jsx` + кнопка 88×31 в подвале.
- **ЧАТ** (`#/chat`) — фейковый живой чат: боты сами пишут раз в 4 секунды.
- **ЛАБОРАТОРИЯ** (`#/lab`) — первые «красивые хуйни»: Матрица на canvas
  и скринсейвер с летающим Internet Explorer.

Плюс везде: бегущая строка (`<marquee>` настоящий), попап «включите IE6»,
звёздный шлейф за курсором, анимированный `<title>`, кнопки 88×31,
мигающие надписи и заголовок в стиле WordArt.

## Как это связано с субдоменами

Сейчас «страницы» — это хэш-роуты (`#/chat`, `#/lab`). Когда дойдёт до реальных
субдоменов (`chat.marselevichk.ru` и т.п.), есть два пути:

1. **Простой** — каждый субдомен отдельная Vite-сборка. Общие стили и компоненты
   (`src/styles.css`, `src/components/`) переезжают в shared-пакет или копируются,
   а в `src/pages/` каждый файл становится точкой входа своего субдомена.
2. **Хитрый** — один билд, а nginx переписывает субдомены на пути:
   `chat.marselevichk.ru → /chat`. Тогда мини-роутер в `src/App.jsx` читает
   `window.location.hostname` вместо хэша — меняться будет пара строк.

Новые страницы добавляются в двух местах: компонент в `src/pages/` + строка
в `ROUTES` в `src/App.jsx` (и ссылка в сайдбаре появится сама).

## Куда цеплять «красивые хуйни»

Кидай новые демки в `src/pages/Lab.jsx` по образцу `MatrixRain`/`BouncingLogo`
(self-contained компонент с `useEffect` + `requestAnimationFrame`) — они уже
обёрнуты в рамку и подписаны.
